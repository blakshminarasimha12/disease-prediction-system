# 🏥 Disease Prediction System

A Machine Learning-based Healthcare Analytics application that predicts diseases from patient medical data using classification algorithms.

## Features

- Interactive Streamlit dashboard
- 10 healthcare analytics visuals
- Disease distribution analysis
- Model comparison
- Confusion matrix
- Feature correlation analysis
- Patient disease prediction
- Prediction probability
- CSV dataset upload
- Model results download

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- Naive Bayes
- Support Vector Machine (SVM)

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit

## Dataset

Place the dataset at:

`data/disease_prediction.csv`

The application also supports CSV upload through the sidebar.

Common target column names supported:

- Disease
- Target
- Diagnosis
- Label
- Prognosis
- Outcome

## Run the Application

```bash
pip install -r requirements.txt
streamlit run app.py
```
